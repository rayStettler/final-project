"You are Not Catherine" Project by Ray Stettler

This project was completed for a critical web design class in spring of 2026. It mimics an online shopping tool that possesses an AI assistant. This assistant observes what the user adds to their cart and makes comments.

This is the login page. The only interactable element is the sign-in button. The username and password are already filled out for a woman named Catherine Howard (her username is cathowie). It introduces the user to the idea that their identity has already been set by the website.

This is the main shopping page. The user may click on items and add them to their cart. The AI will comment on what is bought. There are some items the AI registers as “irregular” (mostly less expensive items), once 10 of these “irregular” items are selected by the user (with any number of “normal” added items inbetween) the AI will conclude that the user is not Catherine Howard, leading it to take the user to a new page.

This project is intended to satirize the way websites, especially shopping websites, track the users behavior, and work to reinforce certain kinds of behavior, especially when it is profitable. The AI assistant is friendly and overly personal, mimicking the way AI is currently being used by many as opposed to human companionship. These dual aspects allow the AI to know a lot about Catherine’s life. When the user does not behave how the program expects, it panics because it interprets that as a potential flaw in its surveillance, and concludes that the user must not be Catherine. Within this narrative, whether or not that is true is left ambiguous. The user is then silently banned from the site, not explicitly, but the login information does not work as the program struggled too much to parse out the user’s behavior.
